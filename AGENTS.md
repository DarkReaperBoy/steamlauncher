# AGENTS.md

NixOS/home-manager flake that reproduces h3adcr-b (SLSsteam + CloudRedirect + optional Steam client downgrade) declaratively. Updated continuation of ItszFinn/nix-crab (upstream inactive since 2026-09).

## Architecture

Hybrid flake with two independent module outputs in `flake.nix`, plus `packages`/`devShells` (the original steam-launcher flake's imperative outputs — ACCELA with a clean-Qt-env wrapper, steam with LD_AUDIT, grabbers):
- `nixosModules.default` — imports `slssteam.nix` (Steam package override, `LD_AUDIT`; Millennium-aware base), `cloudredirect.nix` (`services.flatpak.enable` + `xdg.portal` mkDefault pair + `LD_PRELOAD` via `slssteam.extraEnv`), `downgrade.nix`.
- `homeModules.default` — imports `home.nix` (freeform `settings` merged over the fork's default config, netsock + CLI via `home.file`, CloudRedirect Flatpak via nix-flatpak, `nix-crab-status` with `--json`, `nix-crab-update`), `steamidra.nix`, `accela.nix` (enter-the-wired flake input + Qt-env fix), `luatools-moon.nix`, `millennium-addons.nix`.

Modules are partial applications: `flake.nix` threads flake inputs in via `(import ./modules/x.nix {inherit input;})`. When adding a new module, follow that pattern — do not use `inputs` in the module body.

## Critical decisions (do not "fix" these)

- **`programs.nix-crab.slssteam.settings` is freeform, merged over the fork's own `res/config.yaml`** (`yq-go` `base * overlay`, `pkgs.yq-go` — NOT `pkgs.yq`, which is kislyuk's jq wrapper and silently wrote an empty file; and with `settings = {}` the base is used verbatim, because merging an empty overlay degrades nulls to `''` and switches to flow style). The base is the active fork's config from the pinned input (`slssteam.moon.enable` picks the fork), so the key set tracks upstream with no hardcoded list. This replaced upstream's typed-module + `mkDefault` defaults, which had bit-rotted (`PlayNotOwnedGames` was deleted from upstream C++ in 84c3672 while the module kept writing it). An assertion rejects `settings` without `manageConfig` instead of silently dropping values. Readers are `nix-crab-status` **and CloudRedirect's own `.so`** — both accept `no` and `false`. Do not reintroduce a hand-written YAML renderer.
- **`programs.nix-crab.slssteam.manageConfig` defaults to `false`** — `config.yaml` is left unmanaged so tools like SteaMidra that edit the file keep their changes across home-manager switches (the `xdg.configFile` definition is `lib.mkIf`'d away entirely). Set `manageConfig = true` to have Nix write the merged file.
- **CloudRedirect stays upstream by default; `cloudredirect-moon` is opt-in.** Upstream's `cloud_redirect.so` reads the game list only from `config.yaml`'s `AdditionalApps`, which slsteam-moon deprecated — LuaTools games live in `<Steam>/config/stplug-in/*.lua`. The `cloudredirect-moon` fork (prebuilt `cloud_redirect.so` committed at its repo root) additionally scans `stplug-in` + `luaappids.yaml`. It is NOT the default: `programs.nix-crab.cloudredirect.moon.enable` (defined in both `cloudredirect.nix` and `home.nix`) switches the `LD_PRELOAD` hook and the `~/.local/share/CloudRedirect/cloud_redirect.so` link. Do not make moon automatic or the default.
- **Two-module design by explicit user request.** The user rejected auto-wiring home-manager into the NixOS module and rejected integration/assertion modules (`homeModuleImported`, `nixosModuleImported`, a `programs.nix-crab.user` option). Do not reintroduce flags, assertions, or `home-manager.nixosModules.home-manager` wiring.
- **Steam client follows updates by default.** `steam.cfg` is only written by the downgrade script (`if [ ! -f ... ]`), not by home.nix.
- **netsock is never injected globally** — it's placed at `~/.config/SLSsteam/tools/netsock/netsock.so` for per-game launch option `LD_AUDIT=...netsock.so %command%`, never with anti-cheat.
- Commands are named `nix-crab-*` (`nix-crab-downgrade`, `nix-crab-status`, `nix-crab-update`, internal `nix-crab-dgsc`, `nix-crab-dlm`).
- **`downgrade.nix`: `dgsc`/`dlm` are pinned to commit `8c36338994fdb085fa07b887f71d64362af51c1d`** (upstream deleted them from `main` on 2026-09-28; the commit pin is byte-identical to the old hash pins), and **the manifest + `sources.txt` are fetched at runtime with curl** — they change every Steam build, so fetchurl hashes rotted (both were stale). Runtime fetch matches what `headcrab.sh` does.
- **slsteam-moon builds with `env.NIX_CFLAGS_COMPILE = "-include cstdint"`** — upstream headers use `uint*_t` without `<cstdint>`; GCC 14+ dropped the transitive include and the 32-bit build failed. Force-include beats patching each header.
- **`cloudredirect.nix` sets an `xdg.portal.{enable,extraPortals}` mkDefault pair** — NixOS's native flatpak module asserts both, so without it a plain system fails the build. mkDefault keeps user config authoritative (`extraPortals` non-default definitions replace ours wholesale).
- **`luatools.lumenService` is an opt-in alternative to the `steam`-wrapper sidecar** — with it enabled, Lumen runs as a `systemd --user` service (`nix-crab-lumen`, starts at login, `Restart=on-failure`) and the `steam` shadow-wrapper is dropped. The wrapper stays the default; never run both (the wrapper is conditionally excluded when the service is on).

## Verification

- `nix flake check` in repo root — passes when outputs are valid.
- Test harness at `/tmp/nixcrab-test` (out-of-repo): a flake with `nixosSystem` importing `nixosModules.default` (upstream + millennium + cloudredirect + downgrade configs, and a moon config) + `homeManagerConfiguration` importing `homeModules.default` (full settings/luatools/accela/steamidra, a plain-defaults config, and a `settings`-without-`manageConfig` config that must trip the assertion). Needs `nixpkgs.config.allowUnfree = true` for steam. After editing the repo run `nix flake lock --update-input crab` in the harness — `path:` inputs are locked by narHash, so a stale lock evaluates the OLD code silently.
- Proven end-to-end this way: both NixOS toplevels evaluate; the steam wrapper contains `LD_AUDIT` + `LD_PRELOAD` + `MILLENNIUM_RUNTIME_PATH` together (dump via `nix derivation show`); slsteam-moon builds as **ELF 32-bit x86**; the merged `config.yaml` has every base key + overlay values, comments intact, no flow-style corruption; `nix-crab-status` runs in text and `--json` mode; downgrade script realizes (pinned dgsc/dlm hashes match); home activation package builds; assertion trips when expected.
- Deep home-manager evals (`config.home-manager.users.<u>.<attr>`) can trip a benign upstream `accounts.calendar.basePath` error; don't chase it.

## Gotchas

- **Path-input narHash**: the user's `~/dotfiles` consumes this via `path:/home/finn/Projects/nix-crab`. After editing here, their `flake.lock` must be updated (`nix flake lock --update-input nix-crab`), otherwise `nh`/`nixos-rebuild` fails with a NAR hash mismatch.
- `downgrade.nix` pins SRI hashes for dgsc/dlm/sources.txt/clientManifest — update them when those upstream files change.
- **The `steamidra` input is `api.github.com/repos/Midrags/SFF/tags`, not `releases/latest`** — the releases JSON embeds per-asset download counters, so its narHash changes within the hour and every eval after the tarball TTL dies with `mismatch in field 'narHash'`. Do not pin `narHash` in `flake.nix` either; that makes the same breakage permanent. `/tags` only changes on a new tag, and the newest tag is the first element.
- **SteaMidra's AppImage is downloaded by the launcher at runtime, not by Nix** — there is no versionless asset URL (`releases/latest/download/SteaMidra-linux.zip` is a 404), so a Nix fetch would need a hand-bumped SRI hash per release, which the user rejected. The flake input supplies the version, the launcher unpacks that version into `~/.local/share/SteaMidra/` and runs it via `appimage-run`. Do not reintroduce `fetchurl` + hash or `appimageTools.wrapType2`.
- **The `accela` input is Enter The Wired's `deps.tar.gz`, not upstream ACCELA.** `froster01/ACCELA` publishes no releases and no tags, and its tree cannot live in the store anyway (chdirs into itself, opens `app.log` with `mode="w"`, resolves assets relative to cwd). The Enter The Wired asset URL is versionless, so this one is a plain flake input with the AppImage in the store — no tag-list indirection, no runtime download.
- **`appimage-run` needs `extraPkgs = p: [p.zstd]`** — the bundled PyQt6 links `libzstd.so.1`, absent from the FHS rootfs. Eval and build pass either way; only launching catches it. Smoke-test: `HOME=$(mktemp -d) QT_QPA_PLATFORM=offscreen accela`.
- **`ACCELA.conf` is seeded, never managed** — QSettings rewrites it, so a store symlink breaks it, same reason as `slssteam.manageConfig`. Seeds only when absent; upstream awk-merges the keys into an existing `[General]`.
- `modules/steam.cfg` `BootStrapperForceSelfUpdate` typo was fixed; keep it `disable`.
- `h3adcr-b.sh` in repo root is reference material only — not part of any build.
